Giveaway Bot — Мираторг × Yamaguchi

Telegram бот для проведения совместного розыгрыша Мираторг и Yamaguchi.

- Механика

- Пост в канале с кнопкой «Участвовать в розыгрыше»
- При нажатии открывается Telegram Mini App
- Проверка подписки на каналы организаторов
- Ввод уникального кода участника
- Каждый код = отдельный шанс на выигрыш
- В указанную дату бот публикует победителя в канал

- Стек

- Python 3 + aiogram 3
- SQLite
- Flask (Mini App)
- Telegram Web App API

- Установка

1. Клонируй репозиторий
2. Установи зависимости:
   pip3 install aiogram flask python-dotenv requests
3. Создай .env файл по примеру .env.example
4. Загрузи коды участников в codes.txt
5. Запусти бота: python3 bot.py
6. Запусти веб-приложение: python3 webapp.py

- Переменные окружения

Создай файл .env на основе .env.example:

BOT_TOKEN=токен от BotFather
ADMIN_IDS=твой_telegram_id
RESULTS_CHANNEL_ID=id_канала_для_итогов
WEBAPP_URL=url_мини_приложения

Команды бота

| Команда | Доступ | Описание |
|---------|--------|----------|
| /start | все | Начало работы с ботом |
| /giveaway | все | Участвовать в розыгрыше |
| /load_codes | админ | Загрузить коды из codes.txt |
| /stats | админ | Статистика участников |
| /results | админ | Подвести итоги и опубликовать победителя |
